# Codex + RootFlowAI 链路修复与复测

日期：2026-10-06。执行引擎：MaterialsX 独立 Codex App Server 0.160.0；真实供应商：RootFlowAI `gpt-5.6-sol`，Responses/SSE。本文记录当前源码，历史失败报告保留在 [首次实测](rootflow-gpt56-sol-evaluation.md)。

## 变更范围

- 默认执行引擎改为 Codex；显式选择的 Pi、旧会话和兼容记录保留。本次真实模型试验只用 Codex，没有偷偷切换备用引擎。
- 咨询识别支持否定约束，纯文字建议不调执行工具；云端只读会话无需终端或补丁权限。
- 云端按实际授权给出 JSON 工具名与 Schema，由协议适配转入原生 Codex 的 MCP/终端/patch 循环。没有增加第二个 Agent 或工具执行器，也没有再次执行原生操作。旧 Pi 工具别名不再重复暴露。
- 研究目标解释使用同一 M5 任务、请求 ID、预算与回执的无工具请求，减少原生说明开销；执行仍由 Codex 完成。批准的文件/Skill 是可读输入，不再当作缺失条件；普通脚本用一个主步骤，科学 Skill 读取作为真实计算的前置操作。
- 云端只在所有已发请求确认完成、没有未知操作或在途计算时允许同一会话有限纠错。权限、预算和真实终态未放宽；最多两次无进展纠错。
- 实际退出码非零登记为失败，即便原生 JavaScript 包装层显示 Script completed。不会把文件里的 error 文本当成失败。
- 统一提供并探测独立 Python；不继承用户 PATH，不依赖系统 Python/xcrun。沙箱内单独设置临时目录及 zsh TMPPREFIX，支持真实 heredoc 验证。Python 禁止生成包内字节码缓存。
- 核验科学产物复用原子计算后端，限定当前项目、步骤、版本、真实 job 和文件哈希。单点 3D 使用未弛豫的实际结构；弛豫仍要求真实 final 结构。
- CHGNet/MACE 单点报告补齐中英文并登记计划、环境和报告产物。旧单点记录保持原哈希验证，不给旧文件凭空补回执。
- 输出超限、确认失败和未知用量分别报告；保留供应商真实统计，输出超限不自动重试或扩大预算。

## 验收方法与边界

五类真实试验：设计咨询、Skill 配方放大、Python 错误修复、缺密度数据解释、公开硅结构单点计算。每类检查桌面运行终态、真实平台请求/用量、任务监督回执及实际文件；不是只检查模型文字。修复过程中的失败同样保存在 runtime，最终复测不覆盖它们。

配方是明确标注的合成数据，100 g 湿质量、50 g 固体；放大至 250 g 应得到 125 g 固体。硅结构来自内置公开样例，只做短程探索性单点；结果为 needs_review，不证明 DFT 精度、弛豫收敛或可用于真实配方生产。未导出 MOOS 私有论文、配方或实验数据。

每项任务最多 16 个供应商请求、每次 4096 输出 Token、300 秒。原测试为 3072，不能把配置变化后的速度解释成严格的模型性能对照。供应商未声明窗口时仍使用既有 131072 的宿主请求估算预算，不声称已核实模型实际窗口。真实消耗与已确认 Token 以逐请求回执为准；采购费率/账单未提供，不推算人民币成本。

所有账户/库均为此次创建的隔离测试夹具，结束注销、停止临时服务并删除自有测试库；未修改生产钱包、支付或订阅。所有试验结束后查询到此类隔离测试数据库剩余 0 个。密钥仅由本机私有配置读取，未写入本文、源码或公开日志。

## 工程检查

`npm run check` 包含自有源文件 600 行限制与核心/桌面/管理端类型检查。`npm test` 的真实身份项在无配置时会跳过，另通过隔离 PostgreSQL 夹具运行全部 Go 服务及 8 项真实身份客户端测试；不得将跳过说成通过。桌面与核心开发构建另外执行。当前 459 项工程测试中 458 通过、1 项默认环境下跳过；该身份项已单独在真实服务下通过（8/8 客户端项，零跳过），全部 Go 服务也通过。742 个自有源文件通过 600 行检查，最大 586 行。

当前范围是 macOS ARM64 开发源码与独立运行时。Windows/Linux 原生隔离、正式签名/安装包、全量模型稳定性与科研专家审核未因此取得资格。已有安装包不会因源码构建自动更新。
