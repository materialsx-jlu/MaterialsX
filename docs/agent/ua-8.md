# UA.8：原始实验分析

实现日期：2026-10-06。工程范围为应力—应变内部预览；科学状态始终为 `needs_review`，不是实测仪器认证或正式三场景发布。

## 使用

1. 开发版进入「研究数据与交付 → 原始实验分析」，导入 CSV/XLSX。
2. 确认试样编号、原始列及单位、初始截面积、标距（力—位移必填）、应变测量来源、测试条件和无量纲拟合区间。
3. 必要时填写剔除行号及原因，点击「检查并保存设置」。区间需包含至少三个有效点。
4. 选择试样并填写计算目的，点击「计算并生成报告」，或者「交给 Agent 分析」。不同试样的独立重复必须由用户明确确认。
5. 查看真实曲线、CSV、JSON、双语报告；点击「打开产物目录」，在该目录执行 `node replay.mjs`（Node.js 22+）独立复算。

内置 `@materials-tensile-analysis`，具有中英文描述、两个使用示例和复制到输入框功能。例如：

```text
@materials-tensile-analysis 分析本项目已配置的应力—应变试样，按保存区间计算拟合斜率，生成曲线、数据表、中文报告与复算包。不声明独立重复。
```

未导入或未完成设置时，Agent 只能说明缺项，不能猜测单位、面积、标距或弹性段。此版不让模型修改已冻结的设置；编辑区间后重新开始任务。

团队生成的演示文件：`samples/experiments/synthetic-tensile.csv`。仅用于演示，不是实测证据。可填写：面积 10 mm²、应变单位 1、应力 MPa、区间 0–0.005、应变来源「已报告应变」、条件「合成演示，非实测数据」。得到拟合斜率约 2000 MPa；不赋予杨氏模量，也不生成重复误差条。

## 支持矩阵与科学边界

| 输入 | 支持范围 | 明确拒绝或待适配 |
|---|---|---|
| CSV | UTF-8/BOM；逗号、分号、Tab；首个非空记录为唯一列名；保留物理起始行号 | 本地编码、前置仪器说明、重复/缺失列名、非规则表格 |
| XLSX | 单个可见工作表；首个非空行是表头；数值、内联与共享字符串；常规 Excel XML 名称 | 多工作表、公式、宏、外链、隐藏工作表；不执行单元格公式 |
| 工程应力—应变 | Pa/MPa/GPa；无量纲或 %；明确初始面积和测量来源 | 真应力、压缩/循环/卸载、负应力或负应变、自动调零 |
| 力—位移 | N/kN；mm/m；用初始面积与标距换算 | 面积或标距缺失；未确认测量来源 |
| 数字化曲线 | 显式 `digitized` 身份及误差说明 | 不把数字化误差当作实测重复误差条，不提供自动图像数字化 |

每个输入限 8 MiB、3–10000 行、2–64 列；XLSX 总解压限 16 MiB/256 个成员。原始值保留为字符串，数值计算拒绝非有限值或非数值；只有填写理由的剔除记录可以排除异常行。不会排序掩盖卸载，非单调加载必须显式处理。

输出为指定区间的带截距 OLS 拟合斜率、拟合残差、R²、保留数据内的观测峰值与峰值应变。只有用户确认弹性区间，且数据为实测、应变来自试样引伸计或 DIC 时，才赋值「拟合杨氏模量」，仍需科研复核。横梁位移包含系统柔度，只能报告表观刚度。观测峰值不自动称为极限强度，不自动识别屈服或断裂。

相同测试条件下、不同编号且不同曲线的独立重复才计算样本 SD/SEM；曲线点不是重复。未声明重复则 SD/SEM 为 null。条件以用户保存文本精确比较，暂不推断不同文本是否等价。拟合残差不是测量不确定度，不计算 CI 或自动误差条。

## 同一套架构

- `ExperimentResearch` 是原 `ResearchService` 的伴随服务，共用 `WorkspaceStore/ResearchStore` SQLite、来源失效机制、研究绑定与任务监督；没有新 Agent、工具循环或数据库。
- `experiment_data` 为只读发现/读取；`experiment_analyze` 需要 `read + patch + science`，是原工具注册表里的固定后端。Pi 与 Codex Host MCP 调用相同实现。原始文件只有用户选择导入，不允许模型提供任意路径。
- 任务绑定冻结原始文件及配置 ID/版本/散列；旧配置、跨项目 ID、未选输入、撤回/更正、权限撤销和散列变化拒绝计算。任务运行期间不能编辑。
- 配置及计算回执不可变。编辑后旧结果投影为历史版本；不改写旧计算。输出真实文件及 SHA，任务监督从本步真实工具回执解析产物角色、核验文件，再完成任务。
- 科学计算唯一源码在 `experiments/tensile.mjs` 与 `experiments/math.mjs`。原 UA.7 数值入口改为重导出同一数学实现，删除原重复实现。随程序打包，独立于 Codex、系统 Python、LM Studio 或网络。
- 新界面采用已有目录卡片、全局主题和响应式布局，不新增局部配色设置。

## 产物

原始输入导入时复制到项目 `materials-output/research-quality/<input-id>/original.csv|xlsx`，同时保留解析原值与原始行号 `table.json`，原文件不覆盖。

每次计算写入新的项目目录，包含：

| 文件 | 内容 |
|---|---|
| `result.json` | 完整数值结果、曲线点、输入/配置散列及科学状态 |
| `report.md` | 双语统计、条件、区间、剔除说明和限制 |
| `chart.svg` | 原始转换曲线与拟合区间；仅显示抽稀，计算与 CSV/JSON 不抽稀 |
| `points.csv` | 转换后的无量纲应变/MPa、试样与原始行号、拟合成员标记 |
| `input.json` | 解析原值、单位、几何、来源身份、区间、剔除和重复声明 |
| `params.json` | 请求及不可变配置版本 |
| `environment.json` | 实际 Node/平台/架构、算法及重算输入/脚本散列 |
| `replay.mjs` | 校验输入及代码散列后生成 `replay-result.json` |
| `tensile.mjs` / `math.mjs` | 与桌面相同的固定计算源码 |

单文件输出限 8 MiB，总包限 32 MiB。原始文件与解析表在输入目录受保护；重算包的 `input.json` 已包含相同原值与原始文件 SHA，离线数值重算不依赖原 XLSX 解析环境。

## 验收

- 12 个预定解析参考案例 × 三次运行，覆盖无量纲/%、MPa/GPa、力—位移、区间与模量边界。
- 独立 Python `Fraction` OLS 参考：12 个有残差案例 × 三次，252 个字段，容差 `1e-8 × max(1, |参考值|)`；最大绝对误差约 `1.82e-12`。报告 `runtime/agent/ua-8/numeric-reference.json`。
- 原始文件保留、XLSX/CSV 实际导入、区间版本重算、同源脚本实际执行、输入篡改拒绝、跨项目/路径/符号链接、来源撤回、取消、单位和独立重复门槛通过。
- 实际 Codex Host MCP 客户端与 Pi 注册适配器共用真实后端、冻结配置、权限过滤、原任务监督及产物验收通过；不是 LLM 端到端语义资格证明。
- 真实 Electron 界面：文件导入、设置表单、两次区间重算、历史版本、图表预览、同源脚本复算、中英文和 820/1600 宽度通过；预览抽屉颜色与全局主题一致。报告 `runtime/agent/ua-8/ui.json`。
- 全量 Node 回归：341 项，340 通过、1 个未启用真实身份服务的测试跳过；本轮未重建 PostgreSQL。此前数据库专项复测结果见 [性能与 PostgreSQL 验收](local-performance-postgresql.md)。
- 类型检查、全量构建及 600 行限制通过；默认 Skill 13/13 验收通过。构建仍有已有前端大块/3Dmol eval 提示。

可复跑：`npm run ua8:numeric`、`npm run ua8:ui`、`npm run ua8:verify`。
