# MaterialsX 0.2.0-preview.1 发布候选

本版定位为 **0.2 开发预览版**。发布中心针对预览版显示当前源码与本机环境的检查结果；未完成的正式签名、跨平台实机安装、三领域保留集及回退演练仍逐项显示为提醒，不会因此取得 v1 正式发行资格。

## 本版范围

- 材料研究对话、Skills、模型目录、MOOS MCP 与研究数据交付继续共用同一桌面工作台。
- 本地与平台模型可选；研究计划、工具回执、科学证据和失败状态继续由现有 Agent 链路管理。
- 界面和应用图标使用新的立体原子轨道标识。保留原始与平面版本供后续设计复核。

## 发行核验

发布中心显示“0.2 预览版源码门槛通过”时，表示当前必需的 Skills 数量与许可声明、本地数据库完整性，以及桌面隔离和诊断脱敏检查没有阻断项。它**不等于**安装包、支付服务、材料计算结果或科学结论已经获得正式认证。打包状态、运行时连接、签名、实机安装、科研评测与回退证据单独显示。

生成安装包后，应核对同版构建产物与源码、资源启动回执、SHA-256、平台支持范围和安装实测。当前预览构建仍需明确标注未获得 Apple Developer ID 公证及 Windows Authenticode 签名；Windows/Linux 的原生执行和科学环境以实际打包清单及平台回执为准。

2026-10-07 本机已生成 macOS arm64 核心预览包 `release/dist/0.2.0-preview.1/MaterialsX-0.2.0-preview.1-mac-arm64.dmg`。磁盘映像校验和 ad-hoc 签名完整性检查通过；本机回执 `runtime/release-build/mac/v02-resource-smoke.json` 记录 98 个 Skills、176 项势目录资源、发布中心 6 项通过、6 项提醒、0 项阻断，并在包内界面检查到“0.2 预览版源码门槛通过”。该回执使用隔离的 Electron 资源测试环境，**不构成全新机器安装、Apple 公证或材料科学结果验收**。Windows/Linux 包和实机回执仍待各自平台 CI 生成。

本地验证入口：

```bash
npm ci
npm run check
npm test
npm run build
```

跨平台包由 [预览版 CI 工作流](../../.github/workflows/preview-packages.yml)分别构建和执行资源启动检查。正式 v1 资格仍由 UA.14 的独立签名证据、科研保留集与实机验收门禁判定；0.2 预览版的界面状态不修改该门禁。
