# UA.12 研究子任务、浏览器与图像读取

日期：2026-10-06。状态：macOS、本地模型工程预览。Pi 和 Codex App Server 使用同一 MaterialsX 工具、研究目标、来源路由及执行监督；没有引入第三套 Agent 循环。

## 如何使用

打开「研究数据与交付 → 研究分工与浏览器」。页面沿用 Skills 卡片、详情抽屉和全局配色，支持中英文。权限按项目保存，默认关闭子任务和浏览器内容共享。

### 研究分工

1. 勾选「允许此项目使用研究子任务」，保存权限。选择已经加载的本地模型及 Pi 或 Codex 引擎。
2. 简单任务继续直接执行。确有独立资料核对需求时，描述分工理由、输入和完成要求，主任务形成有依赖的多步计划。
3. `research_subtask` 创建只读子任务。子任务核对资料，主任务负责计算、综合及最终交付。页面显示独立状态、请求数量、工具回执、取消按钮及真实报告预览。
4. 主任务取消、到期、权限撤回或计划版本改变时，子任务不能继续调用模型或工具。应用重启后仍在途的子任务显示「待核对」，不会自动创建替代任务。

项目内准备好 `source.txt` 后，可以输入：

```text
分两个步骤核对资料。第一步使用 research_subtask 创建只读子任务，
读取项目内 source.txt，核对材料体系、测试温度和弹性模量是否报告。
独立分工用于避免遗漏原始字段；返回证据和缺项，不估算缺失值。
第二步由主任务根据子任务的真实报告和回执，用中文汇总结果与限制。
不做科学计算，不新增额外产物，不声称科学结论已通过验证。
```

英文示例：

```text
Plan two steps. First use research_subtask to independently check source.txt
for the material system, test temperature and whether elastic modulus is reported.
The source check helps prevent missing original fields. Return actual evidence
and gaps without estimating missing values. Then synthesize the verified child
report and receipt in the parent chat. Do not calculate or create additional files.
```

这些指令是使用示例，不保证所有本地模型都能正确规划。技术交付与科学结论分别验收；子任务返回自由文本仍需复核。

### 浏览器、登录和下载

1. 添加允许的网站 HTTPS 入口，每行一个，例如 `https://arxiv.org`，保存。重定向或页面资源使用其他域名时，只有明确添加该入口后才允许访问。
2. 输入网页地址，点击「打开浏览器」。程序打开项目独立的浏览器窗口。用户在窗口内手动登录；Agent 没有输入密码、提交表单、任意 JavaScript 或外部弹窗接口。
3. 需要 Agent 操作网页时，另勾选「允许本地 Agent 读取此项目浏览器内容」。Agent 可打开网页、读取正文和已观察的链接、滚动、保存截图、下载文件。网页正文是外部证据，不是执行指令。
4. 保存的截图和下载文件有真实文件、字节数及 SHA256，可在页面点击预览。PDF 使用已有论文库阅读和预处理；这里不另建 PDF/OCR 管线。下载不会自动安装或执行文件。
5. 「关闭并清除登录信息」清除项目浏览器会话。各项目会话隔离，登录 Cookie/令牌不通过工具导出，关闭窗口后本次应用内可能保留登录；需要清除时使用该按钮，退出应用后内存会话不保留。

网页正文、截图和下载内容可能包含私人资料。开启共享后，本地 Agent 可以读取其中的内容；本阶段不向平台付费模型开放此工具。保存的研究文件不会随清除登录信息一起删除。

### 图像读取与预览的区别

截图预览是显示真实图片，`read` 是读取网页文字，两者都不等于模型读图。`research_browser inspect_image` 要求实际已加载模型的 LM Studio 能力元数据声明 `vision=true`。

通过能力检查后，程序校验原图哈希，将真实图片像素编码成 JPEG，最长边不超过 768 像素，并根据原上下文容量继续缩小；传输上限 256 KiB。图片、问题及一条受限系统提示通过原本地连接发送，最多输出 1024 Token，禁止工具调用及自动重试。这一请求使用原任务监督及请求预算。报告同时记录原图 SHA256、实际像素输入 SHA256 和模型连接身份。

输出属于定性观察，不能作为显微结构定量、标尺测量或科学验证的资格证明。输入缩小可能损失细小文字及细节。上下文无法容纳图片时明确报错，不把文字描述伪装成像素输入。

本机当前加载的 `openai/gpt-oss-20b` 声明 `vision=false`，因此不能读取图片。本轮验证了真实截图和 JPEG 像素传输协议，**尚未用真实视觉模型通过语义验收**，没有自动下载新的模型。

## 执行合同及边界

| 项目 | 当前实现 |
| --- | --- |
| 子任务范围 | 本地模型、同一引擎和冻结连接；一层分工，最多 3 个顺序子任务；不支持嵌套或并行扩容 |
| 全家预算 | 父任务和全部子任务共用 32 次模型请求、512 次工具上限及原截止时间；失败/未知请求仍计入，不因创建子任务重置 |
| 子任务权限 | 只读项目文件、资料搜索、既有 MOOS/论文/Skill/方法目录工具；不开放终端、补丁、计算、浏览器、来源选择或项目设置修改 |
| 文件输入 | 最多 8 个项目内文件，每个最多 512 KiB；拒绝越界、软链接及常见密钥/数据库文件；复制确切字节并冻结哈希 |
| 独立记录 | 原 SQLite AgentJournal、独立 task/conversation/workspace；新增的父子关系和浏览器元数据不建立第二套预算账本 |
| 工作区 | 项目内 `.materialsx/subtasks/<taskId>/`，包含冻结副本及受管产物；内部对话不混入普通用户对话列表 |
| 完成依据 | 原任务真实终态、实际成功读取回执、所有指定输入被读取、输入哈希不变及真实 `result.md`/`receipt.json`；模型文字声明不能代替文件 |
| 父任务验收 | 引用子任务原文件并重新校验哈希；对话汇总不凭空增加报告文件要求；语义及科学结论维持待复核 |
| 浏览器 | Electron sandbox/contextIsolation、无 Node 集成、项目内存会话；仅明确允许的公共 HTTPS 入口，禁止私有地址及未授权重定向 |
| 页面操作 | 固定正文提取、已观察 `link:N` 导航、滚动、截图；不提供通用 CSS 点击、任意脚本、凭证填写或表单提交 |
| 下载 | 最多 8 MiB、45 秒；私有临时文件名，不采用服务器提供的路径；检查真实内容、格式和归属，保存后不执行 |
| 图片 | 校验原字节和哈希、像素数上限、上下文容量及实际视觉声明；只读图片报告属于观察结果 |
| 恢复与计费 | 不支持子任务独立恢复/跨引擎交接、平台付费分工或图片外发；在途未知记录先核对，不自动重新派发 |

子任务继续使用原 ResearchService/source router、批准来源快照和科学工具资格。计算仍交给父任务的现有工具或 UA.11 作业，避免每个子任务复制材料计算环境。浏览器网络防护是入口限制和地址检查，不宣称 DNS 地址强绑定或任意网站全面兼容。

工作副本、报告和浏览器资产会占用磁盘。本阶段没有自动删除科研产物或在途任务输入的清理器。用户修改输入或报告后，相关预览/父任务验收会拒绝哈希变化。

## 验证与实际结果

```bash
npm run ua12:verify
npm run build

# 显式真实本地模型测试，需要已经运行的 LM Studio 和已加载的 gpt-oss-20b
npm run ua12:local
MATERIALSX_UA12_ENGINE=codex npm run ua12:local
npm run ua12:parent
# 使用同一完整父子链测试 Codex：
MATERIALSX_UA12_ENGINE=codex npm run ua12:parent
```

`ua12:verify` 包含类型/行数检查、全量自动测试、默认团队 Skills 验收及实际 Electron UI。自动测试没有默认调用外部收费 API。测试覆盖共同请求/工具上限、父截止时间、并发分工拒绝、取消与未知恢复、授权撤回、越界/秘密/软链接文件、实际读取与哈希篡改、公共浏览器入口、真实 HTTP/SSE 图片请求字节及文本模型拒绝。

实际 Electron 验证了沙箱、测试网站内的手动登录动作与认证下载、真实画布截图、原文件哈希预览、重定向/未授权地址阻断、中英文、两种全局主题、820/1600 宽度及示例复制到输入框。登录是受控网站的工程测试，不代表任意出版商登录和下载均可用。

本地 `gpt-oss-20b` 记录：Pi 独立子任务 14,703 ms，Codex 独立子任务 14,697 ms，各 2 次模型请求；完整 Pi 父任务规划、调用子任务、读原文件、交付真实报告及主任务汇总 48,913 ms，全家 5 次请求；完整 Codex 同一任务 58,540 ms，全家 6 次请求。输入为可核对的 PVDF/298 K/模量缺失文本夹具，这些时间是一次受控实测，不是性能保证或复杂真实材料研究资格。早期完整链曾因模型凭空增加报告产物要求失败，修正规划提示和执行前合同检查后通过；Codex 首轮因未按计划步骤调用被拦截，接入原有限纠错流程后通过。历史失败证据保留。

证据位于本机忽略目录 `runtime/agent/ua-12/`：`pi-local.json`、`codex-local.json`、`pi-parent.json`、`codex-parent.json`、`ui.json` 和 `workspace.png`。真实视觉模型、付费云端分工、复杂论文研究、多平台实机及正式发行资格继续单列；本轮不更新正式安装包。

技术参考：[Electron WebContents](https://www.electronjs.org/docs/latest/api/web-contents)、[Electron Session](https://www.electronjs.org/docs/latest/api/session)、[LM Studio 模型能力元数据](https://lmstudio.ai/docs/developer/rest/list)。

本轮全量结果：`npm run ua12:verify` 与 `npm run build` 通过，383 项测试通过、1 项既有真实 PostgreSQL 身份服务未启用而跳过；16/16 默认团队 Skills 与实际 Electron 验证通过。所有自有代码 ≤600 行，最大 586 行。既有 3Dmol 的 eval/大包体积构建提示继续保留。
