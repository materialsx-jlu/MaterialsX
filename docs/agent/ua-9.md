# UA.9：反馈与下一轮实验

实现日期：2026-10-06。支持范围为本机工程预览。复用研究项目、SQLite、任务计划、权限监督及 Pi / Codex 工具循环；没有另建 Agent 或实验室数据库。科学状态固定为 `needs_review`。

## 使用流程

1. 开发版进入「研究数据与交付 → 下一轮实验 → 建立研究条件」。填写材料体系、问题、响应原单位/方向、假设/替代解释/否定条件、实验单元、测量条件、变量/水平/对照、区组/独立制备数、可加工性限制、成本依据和上限。可选目标值是记录信息，不自动判断科研任务完成。
2. 选择全因子 DOE 或空间填充 LHS，填写本轮目的并生成。每个区组包含全部对照及处理点，区组内按种子随机化。计划预算不足时整轮阻止，不截断全因子、不减少重复。
3. 查看候选与顺序表。文件在项目 `materials-output/research-quality/<id>/`：`design.json`、`report.md`、`candidates.csv`、`schedule.csv`、输入/环境和同源复算模块。用 Node.js 22+ 在产物目录运行 `node replay.mjs`，生成 `replay-result.json`；输入/源码哈希变化时拒绝复算。
4. 完成实际实验后，先导入测量来源：UA.8 原始实验计算，或「材料数据」导入带 evidence 的观测 JSON / 选定 MOOS 记录。打开「登记实验结果」，选择对应方案与实验单元、实际变量、来源和说明。测量值由后端读取，不能在表单或 Agent 参数中填造数值。
5. 明确人工核对来源、变量、单位和测量条件。核对仅确认数据录入；不授予科学资格。失败可不含测量来源；工艺/测量条件不同应登记“偏离条件”。这些记录保留在反馈历史，不参与代理优化。
6. 反馈更新同一 `ResearchProject` 的版本。重复使用同一实验来源不能充当新的独立试样；更正通过 `supersedes` 追加，不覆盖原记录。旧方案显示为历史，下一轮使用当前反馈。
7. 数据达到门槛后可选择贝叶斯优化/主动学习，否则仍可 DOE。界面使用 Skills 页的卡片形式、全局深/浅色和中英文。进入页签或点击刷新会重新读取项目输入。

Agent 示例（内置 `materials-next-experiment`，中英文说明、两个可复制示例）：

```text
@materials-next-experiment 根据当前研究条件生成全因子实验方案，包含对照、独立制备、批次内随机顺序和费用检查，输出候选表与报告。
```

```text
@materials-next-experiment 根据已核对反馈推荐下一轮 4 个候选。通过验证才启用贝叶斯优化；数据不足时说明原因并使用 DOE。
```

`next_experiment_data` 分页读取用户条件与实际反馈；`next_experiment_design` 生成固定方法的真实文件。两引擎共享这两个工具、冻结 study/feedback 哈希及原 TaskSupervisor。只读权限不提供设计写入。研究条件和人工核对的反馈由用户界面保存，模型不能伪造人工 review。缺失条件要求先填写界面；此版不替用户猜测物理边界或授权设备运行。

## 支持矩阵与算法边界

| 项目 | 本版支持 |
|---|---|
| 因素 | 1–3 个数值变量，各 2–5 个递增水平；连续或数值离散 |
| 约束 | 变量边界及最多 12 条线性约束；对照必须可行 |
| 实验单元 | 每点每区组 1–5 次独立制备，1–8 个完整区组；单轮最多 400 个单元 |
| 全因子 DOE | 全部保存水平组合；约束删掉组合时阻止，不能继续称为全因子 |
| 空间填充 | 连续变量分层 LHS，离散变量平衡水平；约束破坏分层或重复组合时阻止，不静默重采样 |
| 响应 | UA.8 实测曲线的拟合斜率或观测峰值（MPa）；或来源观测的同名 property、原单位及条件 |
| 反馈 | measured / failed / deviated；不可变更正、真实来源标识、证据和人工核对 |
| 代理 | 单目标固定 RBF GP，长度尺度 0.25，归一化因素；训练分割内响应均值/标准差，固定数值噪声 1e-6 |
| 数据门槛 | 已人工核对、无偏离、来源不重复；至少 8 且最多 64 个不同坐标组合；完整坐标组合留出，重复点不跨训练/验证 |
| 验证门槛 | 固定 seed=8675309，留出至少 3 个组合/约 25%；RMSE 比训练集均值基线至少改善 5%；候选随机种子不改变验证划分 |
| 候选 | 最多 256 个可行候选池；EI/预计成本（贝叶斯）或后验标准差/预计成本（主动学习）；每轮 1–32 个新处理点 |
| 基线 | 同样未测坐标上的 DOE / 随机候选 acquisition-per-cost；这是前瞻模型评分，未建立实际实验优越性 |
| 成本/时间 | 用户给定基础成本、变量增量成本、每单元时间；只是预计消耗，不代表付款或设备执行授权 |
| 科学资格 | 全部保持待复核；候选含预测来源与待核实可加工性；无因果认证、唯一结构解或已完成实体实验声明 |

反馈最多 400 条/项目（含更正）；项目首页保留最近 200 条决策摘要，完整反馈和不可变项目版本仍保留。项目材料体系变更会使旧方案失效；应编辑研究条件并重新生成。编辑研究条件建立新 study，不自动迁移旧 study 的优化资格。用户可重新关联合适来源，但同一 study 中同一原始试样不能重复计数。

导入观测需要 `id`、`property`、有限 `value`、原 `unit`、原 `conditions`，及快照的真实 evidence；可提供 `factors` 与实际变量交叉核对。条件对象按原始 JSON 比较，无静默单位换算。论文/专利中的“报告值”不自动成为团队自己的实体实验；需由用户确认来源与试样独立性。UA.8 数字化曲线不作为此版实测反馈。

工程持留出只用于拒绝明显不合格代理，不等于领域、因果或不确定性校准。连续优化实际加工可行性、区组效应/测量噪声建模、自动功效计算、分类因素、非线性约束、多目标 Pareto、校准预测区间、设备控制及跨天调度未实现。小数据 GP/留出仍可能偶然通过；需要真实领域数据及外部保留集后才能声明研究推荐质量。

## 验收与证据

- `npm run check`：类型、Vue、600 行检查；自有源码最大仍为 586 行。
- `npm test`：359 项通过，1 项真实 PostgreSQL 身份服务未启用而跳过。含 12 种全因子矩阵、随机/区组/控制/重复、预算整轮阻止、LHS 约束、代理通过/拒绝、分组留出/种子隔离、真实来源/事务回滚/更正/撤回/隔离/取消，数据不足的贝叶斯方案转为 DOE 后按末次真实回执验收，以及 Pi 适配器 + 真实 Codex Host MCP 的共享工具/权限/文件验收。
- `npm run ua9:numeric`：12 个固定合成 GP 案例三次，独立 Python 标准库主元高斯消元和 erf 核对 734 个字段。GP 最大绝对差约 1.86e-10（容差 1e-7 × max(1, |参考|)），EI 最大差约 2.80e-7（容差 1e-6）。参考算法独立于 JS Cholesky/CDF 近似。
- `npm run ua9:ui`：真实 Electron 表单、来源导入、DOE/反馈/不足数据阻止、历史、实际复算；中英文、820/1600 窗宽与两套全局配色。输出 `runtime/agent/ua-9/ui.json`、截图和数值报告（忽略的本机验收产物）。
- `npm run skills:accept:materialsx`：默认团队 Skills 14/14 验收通过。能力提示由同一个默认包加载。

以上均为清楚标注的合成或文件级工程验收，没有执行实体实验，没有付费模型调用，也未取得本地/远端 LLM 自主选择下一轮方法的语义资格。真实材料外部保留集、专家评审及 Windows 实机继续待验收。公开安装包未重打包，UA.10–UA.14 按统一计划继续。
