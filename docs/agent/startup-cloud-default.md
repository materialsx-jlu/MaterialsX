# AP.0 默认配置、构建身份与基线记录

日期：2026-10-06。计划：[任务理解与执行可靠性补丁计划](AGENT_RELIABILITY_PATCH_PLAN.md)。

## 已改变的行为

- 首次安装默认平台模型，M5 路由 `materials-research` 对应 RootFlowAI `gpt-5.6-sol`，执行引擎 Codex。
- 旧安装首次使用新构建时，事务保存旧设置并切换平台/Codex；本地端点、协议、上下文/输出预算和任务积分限制保留。迁移后手动选择本地/Pi，重启继续保留。
- renderer 初始化与后端使用共同默认值；保存缺少引擎字段的设置也采用 Codex，修正旧 IPC 的 Pi 回退值。
- 对话输入处显示云端供应商及 gpt-5.6-sol。选择模型不代表账户已登录或网关就绪，调用继续遵守原 M5 授权/计量和项目数据范围。

备份与标记位于本机 SQLite `app_meta`：`startup_model_backup:cloud-codex-v1`、`startup_model_policy:cloud-codex-v1`。备份不会通过现有支持摘要导出。首次迁移整体写失败时，默认选择、备份和标记共同回滚。

回退：可直接在设置里切回本地模型/原引擎，并按备份补回原模型 ID；迁移标记保留，不自动重复覆盖用户选择。运行中任务已有冻结连接和预算不随新设置改变。

## 后续补齐的 AP.0 功能

- 复用 UA.14 `fingerprint`，冻结源码、锁文件、案例、版本与机器信息；同时记录项目独立 Codex 二进制哈希、供应商公共路由/上游名称、协议、输入哈希、权限、预算和真实回执。前后指纹检查会发现批次中途改代码；不将供应商型号字符串当作独立核实的权重身份。
- 桌面构建生成 `dist/build-stamp.json`、`dist/build-identity.json`，主程序嵌入同一构建标识。实际 bootstrap 及脱敏支持包返回身份检查；主程序、preload、renderer 与桌面辅助文件按字节核对，新增、缺失、修改或载入另一构建均不标已核对。源码映射、测试/smoke 排除，与生产排除规则对应；此清单不代替签名或全部第三方科学运行时校验。
- 复用现有 `rootflow-evaluation.ts`、`rootflow-baseline.ts` 和隔离 M5/PostgreSQL 测试服务。合成原始数据、错误脚本及修复请求共用一个 fixture，删除原两入口重复的合成输入。工具和监督仍由原引擎执行。
- 基线入口默认仅采集，不发生成请求。真实生成必须显式 `--live`；每次独立目录保存输入、前后指纹、结果、日志哈希及失败/未知状态。只读取本次子进程的报告，不用旧的 latest 成功结果填补缺失报告；真实任务失败返回非零。
- 分开记录首个界面反馈、首个模型文字、首个协议 delta、模型请求、工具、计划准备、宿主纠错续接、宿主交付核对与基准文件检查。观测不新增模型请求，不更改计划、权限或计费；观测消费者异常不能导致工作失败或重复执行。

### 时间口径

`firstUiDeltaMs` 包含进度文字；`firstContentMs` 来自克隆 SSE 中第一个非空 `output_text.delta`，不是工具参数。请求耗时包含网关、网络、模型及流，不是纯供应商计算时间。工具耗时来自原 journal，重叠区间合并后再统计；未结束操作保留未知终点，不记为零。

`timings.stages` 分别记录计划准备、宿主纠错 continuation、引擎返回后的宿主验收；无阶段观测的旧报告为 null，不补造数字。宿主纠错续接不是原生循环中全部脚本修复耗时；脚本失败、读源码、patch、重跑可从工具/请求时间线核对。阶段可能包含请求/工具，不能相加冒充总时间。尾部及未分类时间单列，不能全部认作宿主纯开销。

### 使用命令

```bash
# 构建主程序、renderer 并封存身份清单，不调用模型
npm run build:desktop
npm run ap0:identity

# 仅冻结当前基线，并检查指定旧应用包；没有生成/支付
npm run ap0:baseline -- --app /path/to/MaterialsX.app

# 明确启用真实供应商测试，仍走原 M5 和 Codex
npm run ap0:baseline -- --live --app /path/to/MaterialsX.app

# 实际开发应用启动与页面检查，使用隔离用户状态
npx electron apps/desktop/ua0-ui-smoke.cjs
```

供应商凭据仅从既有本机私有配置读入内存，不复制到报告、源码或安装包。真实入口需本机隔离 PostgreSQL 服务和既有已审查供应商配置。默认离线采集不需要账户登录，不能因此标记账号/网关就绪。日志和模型回答包含合成测试内容，仅保存在忽略的私有 runtime 目录；公开说明只列汇总和限制。
