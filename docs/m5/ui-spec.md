# M5.0 界面草图与状态合同

可审阅草图：[ui-wireframe.html](ui-wireframe.html)。独立本地 HTML，无外部资源和网络请求；界面不是生产功能，所有收退款、登录、生成和发布动作禁用。

## 桌面页

采用 Codex 浅色配色及现有深色方向，沿用 MaterialsX 品牌、中文主文案和英文模型/来源。顶部分段导航为 Agent、供应商、网关、路由、用量、资源库。默认进入供应商，卡片和详情并列，小屏改为纵向。

| 页面 | 主要元素 | 状态处理 |
| --- | --- | --- |
| Agent | 本地/平台模型、任务 credits、调用/输出/时间预算、云数据说明 | 未验证模型不能保存为可调用；预算是用户上限，实际预留由服务端计算 |
| 供应商 | 搜索、RootFlowAI/LM Studio 卡片、来源/目标模型/能力/价格详情 | unconfigured/unverified/available/limited/failed/disabled；普通用户不见 Key 编辑框 |
| 网关 | 登录/连接、协议、延迟、脱敏诊断 | 未测用“—”；离线显示原因和重新连接入口 |
| 路由 | 公开别名、实际供应商与目标模型、版本 | 不可用时保持目标而提示原因，不静默换模型 |
| 用量 | 可用/预留/待对账、订阅、套餐、订单、任务账单 | 未登录不显示虚构余额；待对账不是免费或满额扣款 |
| 资源库 | 内置84 Skills、100目录、云模型、许可与能力 | 目录≠权重；模型未实测不标就绪；M6另验收 |

真实云模式外发前说明必要消息/分页证据/工具结果范围和供应商；原 PDF 不整份自动上传。流式继续复用现有缓冲与 Markdown/公式排版，工具状态与回答分开；完成、取消、失败、待复核、待对账具有独立呈现。

购买显示人民币价格与有效期、退款政策版本、手动续费；没有发布销售价格时入口禁用。订单付款等待/成功/失败依据服务端确认，浏览器成功页不能授予权益。

## 独立运营中心

草图提供切换入口仅供设计审阅，实际后台部署为独立 Web，不在普通桌面隐藏一个管理员页面。首版单一具名管理员/MFA，预留细粒度权限组。

包括工作台、用户与设备、订单、权益、退款、用量成本、供应商路由、版本发布、客服公告、审计。退款展示原订单、试算/冻结、人工审批和渠道结果；版本展示草稿、commit/架构/哈希/签名/许可、门槛与发布结果。

数字未知显示“—”，不会把下载数当安装人数、注册数当全部本地用户、缺失采购成本当确定利润。账号/工单默认无科研正文；用户主动上传的诊断需告知范围。

## 交互验收与实现阶段

- 草图可切换六导航、供应商详情、搜索、主题及运营模块；不存在真实网络/业务动作。
- 已提供按钮可见焦点和输入标签，选中不只靠颜色；小屏保留信息顺序。
- loading/empty/offline/forbidden/error/partial 状态在 MX-506 的真实 Vue 接线时验证，中英文完整文案随接口错误映射回归。
- 运营中心的完整界面合同继续以 [运营计划](../M5_OPERATIONS_CENTER_DEVELOPMENT_PLAN.md) 为准，草图不取代财务审批和正式后台开发。
