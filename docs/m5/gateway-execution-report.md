## 当前限制和下一步

M5.3接事务资金账本、售卖价/采购对账、pending恢复worker、完整材料任务预算与预留结算；退款/支付与正式运营后台属后续工作包。当前累计次数仅为技术测试授权，unknown请求不能自动退款/返还或重试。

本期云工具仅支持选定UTF-8文本与Skill说明；不支持完整PDF/RPSME/XYZ脚本链、MCP或任意本地执行。平台Pi历史仅进程内保存，登录/重启不会自动上传本地旧聊天；任务ID索引与PGusage可继续查询。

供应商上下文容量、模型来源、采购价/消费日志、商业数据条款、上游停止、公网生产TLS、Windows实际UI仍未验证。服务端默认disabled，实际运营部署要设置私有配置、重新授权受限数据库角色、授予测试账户并通过目标环境验收。不会把此交付称为付费产品上线。
