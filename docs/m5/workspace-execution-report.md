# M5.5 本机执行报告

日期：2026-10-01。MX-506 的桌面云服务中心与独立运营后台已完成本机技术验收。测试环境为 macOS arm64、真实 Electron main/preload/Vue、同源管理员 Vue、隔离 PostgreSQL；模型输出与支付金额为合成测试数据，没有真实扣费或公开发布。

## 交付范围

- 桌面 Agent、供应商、网关、路由、用量、资源库六项导航；中英文、浅/深色；84 个内置 Skills、100 条模型目录及例子填入输入框。
- 独立查询最近 7 个 UTC 日的账户调用趋势、钱包/冻结/回收、任务账单分页、请求阶段明细、系统保存对话框导出 CSV。未知 Token 保持未知，科学质量不以任务成功代替验收。
- 独立后台的管理员密码 + TOTP、用户与会话管理、订单/退款核算审批、用量核对、供应商路由、公告/暂停准入、版本目录和审计。权限继续使用服务端 cookie、CSRF、Origin、对象归属、版本与幂等检查。
- 新增 005 数据库迁移和运行角色授权；既有 001–004 保持不变。隔离本机测试基础库已升级至 005；部署环境需自行备份、升级并重新授权。
- 版本目录采用人工 GitHub 发布后只读核验的流程；部署侧审批文件绑定不可变清单。真实签名、安装、示例数据权利及公开 immutable Release 等证据缺失时拒绝发布。没有 GitHub 上传/写令牌、自动更新或模型权重下发。
