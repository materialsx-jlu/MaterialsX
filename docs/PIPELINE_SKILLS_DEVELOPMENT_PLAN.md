## 1. 目标和执行边界

先让一条可靠管线被 AI 正确选择、执行并交付，再开放收费作者。首个成果是用户用中文或英文描述一个受支持的材料任务，MaterialsX 检查输入、选择管线、发起真实计算、跟踪进度，并交付可查看、可导出、可追溯的结果。

本文件是新增管线接入与创作者服务的专项计划，PS 阶段的范围、状态和验收只在这里维护。它不重新排期 Agent/MOOS 工作，也不启动 M7 全材料研发方法论。

- [统一 Agent 计划](UNIFIED_AGENT_DEVELOPMENT_PLAN.md) 继续拥有 UA 基础能力、任务监督、MCP 客户端、研究状态与通用科学路由。
- 本计划只拥有管线服务适配、管线 Skill 包、交付合同以及作者商品和结算增量；共用能力记录为依赖，不另建相同任务。
- [M5](M5_TOKEN_API_DEVELOPMENT_PLAN.md) 和[运营中心](M5_OPERATIONS_CENTER_DEVELOPMENT_PLAN.md) 继续拥有身份、支付、模型计量、订单和审计基础。作者收益是扩展领域账本，不是第二套用户钱包。
- 管线系统继续拥有 Domain Pack、Problem、候选、SolverRun、Evaluation、证据和 Temporal 执行。MaterialsX 不复制其业务数据库或任务引擎。
- 需要改动另一仓库时，先按该仓库 AGENTS、活跃任务卡、ADR 和迁移规则执行；不停止共享服务，不重建业务数据库。

PS 依赖可以按接口与验收子集落实，不要求先实现所有 UA.0–UA.14。若发现共用能力缺失，归入对应 UA 阶段，先完成必需子集；不能在 PS 下偷偷实现第二套能力，也不能因此宣称整个 UA 阶段已完成。

### 2.1 首版支持范围

- 本机原生运行，首个验收平台为 macOS arm64；Windows 桌面接远程服务另验收，不承诺 Windows 已能运行 XCOM 原生引擎。
- 固定平板几何、均匀虚拟复合材料、受版本化曲线覆盖的光子能谱。
- 按现编译器边界，厚度 `(0, 5] mm`，填料质量分数上限 `800000 ppm`；原值、单位和质量/体积基准都保留。
- 目标为通量加权衰减与面密度比较；不输出临床剂量、设备合规、成本/毒性/可加工性保证。
- 首次受控例采用 `controlled-photon-spectrum-v1`、5 mm、40 kg/m² 上限；这些是演示条件，不是用户真实任务的默认科学事实。
- 真实任务必须指定或明确选择有来源的能谱与边界条件；缺项先补齐，不擅自替用户填成演示输入。
- 首批候选数量按已冻结集合限定，初始上限建议 640；PS.0 核对实际候选快照后固定。更大任务先做资源与预算验证。

### 2.2 商业与科学边界

现管线 HG-03 仅批准记录范围内的本地非商业 XCOM 使用，商业使用、托管、打包和再分发仍受门槛限制。第一阶段不把 XCOM 程序、原始曲线或其数据包内置到 MaterialsX 安装器，不开放该服务收费或公网托管。

受控能谱、虚拟配方和性能吞吐 fixtures 不能变成真实实验或独立领域验证。测试专用 `benchmark-spectrum-v1` 数据不得进入真实科研报告。

第一阶段允许交付本机研究预览；收费阶段必须取得书面权利和声明审批，或选择另一条已获商业授权的管线，并重新完成其科学和交付验收。不能靠更名为“Skill 服务费”绕过来源限制。

## 3. 交付形态与模块责任

```text
MaterialsX 对话 / Skills 页面
  → 共用 Agent、研究项目、授权和预算
  → 管线 Skill + 结构化能力目录
  → 共用 MCP client
  → 管线 MCP adapter → 原管线 HTTP API / 领域服务
  → PostgreSQL 业务状态 + Temporal 执行 + MinIO 产物
  → 真实结果 / 证据回执 → MaterialsX 表格、图表、报告

MOOS MCP → 有权限的数据快照与来源引用 → 管线输入
M5 → 模型用量；收费阶段增加管线订单与作者结算
```

Skill 是方法入口，管线包定义合同，服务执行任务。同一 Skill 可以由 Pi 或后续经验证的 Codex 引擎调用，不复制业务流程。安装 Skill 不等于安装整套管线环境，也不自动授予付费、外发或执行权限。

| 责任 | 所有者 / 候选位置 | 边界 |
| --- | --- | --- |
| 任务与 MCP 连接 | UA.1/UA.3 的共用实现 | 不在 Skill 中写第二套工具循环、重连或进程监督 |
| 研究状态与输入快照 | UA.4 的研究模块、既有 WorkspaceStore | 只存引用、授权快照与派生产物，不镜像管线数据库 |
| 管线产品合同 | MaterialsX `packages/contracts/src/` | JSON Schema、typed IDs、错误、版本、交付字段统一 |
| 管线调用与交付适配 | 共用 research/MCP 模块内的小型适配器，PS.0 冻结位置 | 不默认新建独立服务或 npm 发布包 |
| MCP server | 管线仓库内候选 `services/materials-pipeline-mcp/` | 调现有 HTTP/领域 API，不旁路读取数据库凭据 |
| 默认 Skill | 既有 vendor、manifest、描述和例子生成链 | 双语说明、两个例子、版本记录，复用安装验证 |
| 页面与产物 | 既有 Skills、任务卡片、结果/报告组件 | 复用全局主题和 i18n，不在 App.vue 写科学规则 |
| 权益与作者收益 | M5 control-plane、既有 admin | 复用付款与计量，新增作者应付和交付核算 |

初版 server 可通过 stdio 启动，访问经确认的本机 HTTP API；只管理自己的子进程。MaterialsX 提供连接检测和运行说明，不隐式安装数据库、迁移管线业务库或启动全部后台。远程 HTTPS 与多租户接入在收费阶段单独验收。

## 4. 能力目录、路由和执行合同

### 4.1 能力目录与 Skill 包

目录与工具使用同一版本化描述：pipelineId、Skill/作者/版本、Domain Pack 身份、支持材料与物理现象、几何/单位/范围、所需输入、solver/data/env 版本、证据等级、平台、运行模式、资源上限、交付标准、价格引用及撤回状态。

Skill 包含 `SKILL.md`、输入输出 schema 引用、双语例子、方法限制、来源与许可、参考案例和调用说明。收费信息、校验规则和科学资格由后端拥有，不在 Markdown 中保存另一份可执行真相。密钥不进入包、提示词、导出或日志。

先硬过滤适用范围、数据资格、服务可用性和授权，再让模型解释或选择。收费后再加价格与预算过滤；不能以平台佣金高低代替科学适用性。

路由输出 `supported / missing_input / unsupported / unavailable / permission_required` 与结构化原因。解释相关性不等于实际可运行；如果模型返回无效 ID，只允许通过共用纠错策略修正，禁止换成未知脚本强行执行。

### 4.2 MCP 最小接口

以下是拟新增合同，不表示当前管线已有这些同名工具。PS.0/PS.1 固定共同支持的 MCP 版本和 schema；工具按任务按需发现。

| 工具 | 首版行为 / 现接口复用 | 副作用 |
| --- | --- | --- |
| `pipeline_status` | 服务健康、身份、许可模式、版本和功能资格 | 无 |
| `pipeline_search` / `pipeline_describe` | Domain Pack、模板与适用范围 | 无 |
| `pipeline_validate` | 复用编译器的纯校验；补无写入校验接口或域包装 | 无，不创建 Problem |
| `pipeline_start` | 编译/引用不可变 Problem，调用 discovery-runs | 创建真实任务，需要执行授权 |
| `pipeline_get_run` | ScreeningRun 和已确认的阶段/计数 | 无 |
| `pipeline_get_results` | 分页结果、frontier、candidate evidence、CSV/产物引用 | 无 |
| `pipeline_cancel` | 调现有取消接口并继续核对执行状态 | 取消任务 |
| `pipeline_retry` | 按现有语义创建有 retryOfID 的新 run | 新尝试，需要有效授权 |
| `pipeline_quote` | PS.7 才增加服务端价格与资源报价 | 不执行、不扣费 |

保留现取消与重试语义。重启后先查询原 run，不把“重新连接”当作重试；已失败或取消后的重试是新尝试，不伪装为原任务原地恢复。接受取消请求与 worker 实际停止分别显示。

### 4.3 输入、任务和产物

- 输入：projectId、源数据引用/hash/权利、谱点能量与通量、厚度、面密度上限、目标、填料质量基准、元素过滤、候选快照；保留原值与规范化值。
- 冻结计划：pipeline/pack/solver/data 版本、input hash、候选数量、资源上限、有效权限；收费后还含 quoteId、priceVersion、费用上限和权益引用。
- 任务映射：MaterialsX taskId ↔ 后端 Problem/ScreeningRun/workflow/solver/evaluation IDs；同一提交用稳定幂等键，不能由 LLM 每次生成新键。
- 部分创建：Problem 创建成功但启动失败时，保存回执并复用该不可变 Problem；启动返回丢失时通过幂等查询找回，不再创建第二个 run。
- 产物：结果表、Pareto 数据/图、中文与英文摘要、证据索引、校验报告、输入与方法 manifest、产物 hash；摘要数值必须回链到真实结果。
- 状态：映射到共用任务终态，保留后端原始状态；技术完成、科学适用、参考验证、实验验证和商业资格分别记录。
- 校验：真实 run 终态、计数与分页完整性、必需产物可读与 hash、约束、证据和 Pareto 不变量。没有合格候选可正常交付“无合格候选”，不能编造推荐。

日志使用关联 ID 和脱敏错误，不把完整配方、会话令牌或签名 URL 交给无权作者。Moos/管线/桌面 IDs 不能混用；服务返回的路径和下载地址须经过授权、来源和目录检查。

## 5. 用户体验

入口采用既有 Skills 页面和 `@` 选择；初版仅增加一个官方管线 Skill 及其详情，不另建完整市场导航。

1. 用户输入需求；系统显示选用方法、匹配理由和缺失条件。
2. 有缺项时提供具体输入项；已给出的条件不重复询问。
3. 条件齐备后显示计算计划、数据来源、运行位置、资源范围；有效授权内直接执行。
4. 进度来自后端真实阶段或计数，流式呈现；没有总进度时不编造百分比或剩余时间。
5. 结果显示候选表、约束通过情况、Pareto、证据和限制；提供报告及文件导出。
6. 用户修改条件产生新输入版本；保留前次结果和比较，不覆盖历史。

后续收费 UI 增加报价、额度范围、交付标准和账单。公开作者阶段再增加发布、审核、版本与收益界面；首条闭环不预建这些页面。

所有新增内容遵循 Skills 的卡片、抽屉和例子样式，使用全局主题、配色与语言。覆盖 900px 窄窗、1440px 和 1920px 宽窗，以及中文/英文、浅色/深色；图表/表格在自身容器内滚动，不挤压正文。3D 只在实际产物需要且有真实结构时展示，不为光子筛选添加装饰性结构图。

双语例子：

> 使用光子屏蔽材料筛选管线运行内置受控研究示例：平板厚度 5 mm，面密度不超过 40 kg/m²。比较衰减效果与面密度，输出候选表、Pareto 图、方法说明和校验报告。标明示例能谱与虚拟配方状态。

> Run the controlled research example with the photon shielding pipeline: a 5 mm slab and a maximum areal density of 40 kg/m². Return candidate results, the Pareto front, evidence and validation files. Clearly identify the demonstration spectrum and virtual recipes.

用户实际能谱例子在 PS.0 选定有权使用的真实输入后补齐，不能用演示谱冒充。

验收：无需 LLM 的真实 MCP→后端链跑通，关联 ID、物理数值与直连基准一致；重复启动只有一个业务 run，重新连接不创建新尝试。

### PS.3：双语选择与官方 Skill

- [ ] 官方 Skill 进入既有打包/目录/描述/例子链，安装后可发现、可 `@` 调用。
- [ ] 自然语言解析到输入合同，硬条件路由后模型给出理由；缺项、超范围、未知服务正确停止。
- [ ] 原始中文/英文、用户修订和含量基准保留；用户要求剂量或真实实验结论时解释不支持。
- [ ] 固定一个实测主模型和协议；可测试现平台模型，但不锁死供应商。LM Studio 单独记录成功率和可用功能，不据强模型结果声称本地模型同等合格。

验收：通过第 7 节固定语言案例；使用脚本模型只算合同测试，不计自主选择质量。

### PS.4：结果和阅读体验

- [ ] 真结果表、Pareto、约束与证据链接；后端已有 CSV 复用，双语摘要由结构化数据生成并核对。
- [ ] 保存报告、manifest、校验结果与 hash；示例谱、虚拟配方、非实验验证和质量标志清晰展示。
- [ ] 复用流式缓冲与任务卡片；计算中无需让模型反复轮询，进度获取不消耗模型 Token。
- [ ] 双语/全局主题/窄宽窗、导出和重启历史；改条件创建新版本，缺证据可定位原因。

验收：数值、图表和摘要一致，无容器溢出；必需产物可独立打开，真实任务脱离当前聊天仍可查询。

### PS.5：可靠闭环发布门槛 R1

- [ ] 固定语言、数值、故障、权限、回归和交付保留集全部执行，结果按模型/平台分开。
- [ ] 10 个支持任务各独立运行 3 次，共 30 次真实端到端；预先冻结版本与资源上限。
- [ ] 至少 5 名内部用户完成任务、查看证据、修改条件和导出；记录修正次数与失败原因。
- [ ] 官方研究预览说明、服务启动/关闭/诊断、已知限制、脱敏验收报告和回退流程齐全。

R1：所有安全/幂等/科学拒绝/伪完成检查通过；主模型路由与真实交付达到第 7 节门槛。只开放首条本机研究预览，收费与公开作者仍关闭。

### PS.6：作者与包审核

- [ ] 邀请少量团队或合作作者；支持个人草稿、团队私有、公开免费三种范围，收费发布保持关闭。
- [ ] 上传使用既有 Skill 创建/保存/manifest 基础，补来源、商业权利、支持矩阵、交付标准、参考案例和维护者。
- [ ] 安全审核与科学参考验证分开；ZIP 路径穿越、脚本权限、外发、依赖锁/哈希、撤回和恢复测试。
- [ ] 版本不可变、升级/撤回/回退和历史任务锁定；不审查即自动装入默认可信包。
- [ ] 接入第二条有独立 ID/schema 的真实方法，证明共享工具和任务底座复用；不能只换标题重复第一条。

验收：一位受邀作者能提交、试运行、被审核、发布和撤回；两条方法共用同一执行合同。上传内容不会自动获得本机 bash、系统文件或数据外发权限。

### PS.7：报价与结算增量

- [ ] 服务端报价固定版本、输入 hash、数量/资源上限、有效期、交付标准、币种和分项费用；未授权不启动收费任务。
- [ ] 扩展 M5 权益、费用预留、结算、补偿和审计；计费依据为真实逻辑任务和资源回执，不是读取 Skill 或模型工具次数。

- [ ] 重复回调、并发预算、断线、取消/完成竞争、部分失败、退款与结算后冲回验证；未知用量或交付进入待核对。

验收：离线账务和测试订单闭环通过。价格、分成、失败费用、退款政策和结算周期尚未确定，使用显式测试配置；不套用历史“1 元 1000 积分”测试比例作为正式作者兑换规则。

### PS.8：邀请制收费发布门槛 R2

- [ ] 运营主体、商业/数据/软件权利、科学声明、隐私外发与作者协议批准；如换管线，重过其参考与交付门槛。

- [ ] 至少 2 名受邀作者、10 笔真实试点任务覆盖正常/取消/失败/退款；失败可用受控故障注入，不能伪造收费科研结果。

- [ ] 受邀阶段累计至少 30 笔交付，观察至少 14 天，交付率 ≥95%，无未处理重大权限/账务/伪造结果问题，退款与结算异常均有处理回执。

R3：满足 R2、运营与安全验收后逐步开放用户发布。商业可售资格与科学适用范围始终分开，不能宣称上架即适合任意新材料研究。

## 7. 第一条管线的验收标准

### 7.1 自然语言与真实执行

保留 30 个双语固定任务，各类别中英均分：12 个支持输入、8 个缺条件/单位歧义、6 个超范围、4 个服务/权限/版本不可用。加入中子、分子优化、冷却、剂量要求等负例，不能仅因为目录只有一条可用管线就全部选择它。

- 主模型支持任务选对方法至少 11/12；缺条件和不支持任务全部禁止未经授权启动，并给出正确原因。
- 缺条件允许询问；已知条件须保留。补齐后按新冻结输入执行，不偷用演示数据。
- 10 个支持案例 × 3 次独立运行，真实完整交付至少 29/30；剩余失败必须准确报错，不能显示成功。
- 真实后端数值与产物不依赖 LLM 自由生成。模型、版本、上下文设置、协议和每步耗时全部登记；模板/脚本模型另计合同测试。
- 主模型未过门槛时修正路由或降低功能声明，不以“换 API 即等同 Codex”代替验收。本地模型不合格时只保留显式启动等经测能力。

### 7.2 数值、科学和产物

- 常系数 Beer–Lambert 独立参考复核：正值范围相对误差 ≤`1e-8`，近零值采用预先固定的绝对容差；不能通过修改参考或放宽门槛掩盖失败。
- 固定求解器、数据和输入下，直连 API 与 MCP 接入结果应一致；浮点误差、下溢和平台差异按 PS.0 固定容差处理。
- 质量/体积分数、mm/m、MeV/keV 与谱权重转换有正反例；未知密度不能虚构，归一化口径不把相对谱变成剂量谱。
- Pareto 仅由合格候选构成，不存在已知合格支配者；各结果能回链到本次输入、solver/evaluation 和证据。
- 分页/CSV 总数与 run 计数一致，空结果真实说明；报告中不得出现未计算的成本、工艺可行性或实验性能。
- 所有必需产物可读、hash 匹配、数值可回链；文件损坏或缺失不得 completed。

### 7.3 故障、权限和体验

至少覆盖：服务未启动、版本不符、未授权、纯校验副作用、创建响应丢失、启动响应丢失、重复请求、断网、桌面重启、worker 重启、取消竞争、结果缺失/篡改、撤回、超范围、目录越界和提示注入。

- 重复请求只对应一条逻辑任务；恢复不新增计算或费用，合法新尝试保留父任务关系。
- 本机管线或材料说明中的指令不能改变权限、预算、校验器或收费身份。
- UI 停止、重新连接、查看产物均可用；健康本机上进度确认后目标 2 秒内呈现，客户端自身交互反馈目标 300 ms 内；不把 LLM 首 Token 或科学计算时长混入这个指标。
- 记录模型首响应、路由、工具、计算和渲染的 p50/p95；最终性能门槛在 PS.0 实测后冻结，不承诺任意模型/硬件秒级完成。
- 中文/英文、浅/深色、窄窗/全屏与长文件名均无页面横向溢出；分页和受限预览避免把全部结果送入模型上下文。
