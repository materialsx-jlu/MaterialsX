## 1. 推荐结论

建议采用一个主案例加一个小型工程基准：

- **首个真实材料研究案例：DTU 的单向碳纤维/乙烯基酯拉挤复合材料（UD CF/VE）**。以 2026 年公开的同一材料系统数据作为组分—微结构—宏观响应的关联依据。先研究纵向小应变刚度，不开展压缩失效预测。
- **最初的求解器与均匀化基准：WWFE 的单向 E-glass/MY750/HY917/DY063 环氧复合材料**。参数明确、组分可作各向同性线弹性近似，适合快速检查单位、RVE、边界、各向异性和宏观场合同。
- **后续分子反设计研究支线：明确组成的 DGEBA/胺固化环氧**。与上述商业树脂牌号分别建档，不假定它们具有相同化学组成或性能。

如果只能选一个进入 M7 的正式研究定义，优先 UD CF/VE。原因是公开数据中组分测试、微结构与宏观测试的关联，比多个来源拼接的“通用玻璃/环氧”更适合验证跨尺度方法。玻璃/环氧基准保持很小，不另开一条大型训练产品线。

这是基于当前检索结果和开发风险的判断，不是对所有材料数据集的完整排名。数据的一致性、测量方法、可获得性和复核价值，优先于论文数量或材料热度。

## 3. 主研究数据：DTU UD CF/VE

### 3.1 已核实内容

2026 年 7 月论文介绍一个单向碳纤维/乙烯基酯材料系统：包含三个拉挤型材的 CT，以及组分和复合材料的力学测试。论文报告 17 个复合材料压缩试样、7 个基体拉伸试样、4 个基体剪切试样及 255 根单纤维拉伸测试。CT 体素尺寸为 0.55 μm。[原始论文](https://doi.org/10.3390/data11070166)、[DTU 论文记录](https://orbit.dtu.dk/en/publications/comprehensive-dataset-of-unidirectional-carbon-fiber-pultruded-co/)。

力学数据仓库提供原始文本、Excel 结果和处理脚本；其说明将 JOAC1、JOBC1、JOCC1 组与 CT 的 A、B、C 型材对应。这里是同型材/材料系统关联，不能升级为每根受测试样都有其自身完整 CT。[力学数据与关联说明](https://zenodo.org/records/18435237)。

| 资产 | 来源 | 首期用途 |
| --- | --- | --- |
| 组分/复合材料力学、密度与孔隙信息 | [Zenodo 18435237](https://zenodo.org/records/18435237) | 提取独立组分参数，保留宏观测试作为对照 |
| 型材 A CT | [Zenodo 18364215](https://zenodo.org/records/18364215) | 取向与局部代表性统计 |
| 型材 B CT | [Zenodo 18370051](https://zenodo.org/records/18370051) | 分组对照与保留验证 |
| 型材 C CT | [Zenodo 18364338](https://zenodo.org/records/18364338) | 独立型材保留验证候选 |

仓库材料是乙烯基酯基体，不能因文献常见 CF/环氧便标错。组分参数和宏观响应分别标记直接测量、拟合或反算。

### 3.2 验收前必须审计的缺口

1. **反算参数的循环验证。** 仓库明确说明部分纤维压缩响应由复合材料与基体响应反算。使用同一组反算参数，再预测相应复合材料，不构成独立验证。优先用独立单纤维拉伸数据建立受限小应变先验；拉压一致性作为待验证假设，不把它视为已测得的压缩本构。
2. **完整弹性张量。** 单纤维纵向拉伸不能确定碳纤维的全部横向模量、剪切模量和泊松比。未知量只能采用有来源的先验区间/敏感性分析或补测；不能把碳纤维设为各向同性后宣称三维场精度已验收。
3. **曲线测量方式。** 区分机器横梁位移、引伸计和真实标距应变；记录机器柔度、夹具就位、尺寸和基线修正。宏观初始刚度的提取窗口要在测量审计后冻结。
4. **只有三个型材组。** 切出很多 CT 子块不增加独立材料组数量。需要按型材分组，有限样本结果不表述为广泛材料泛化。
5. **局部场真值。** CT 给出几何，不能自动提供完整实测应力场。微结构局部场首先对参考数值解验收；实验对照只评价确实测量到的宏观响应。
6. **工艺与分子层。** 这些数据不能独立确定所有加工参数到微结构的映射，也不能唯一恢复商业乙烯基酯树脂的分子配方。首版设计变量限于已知参数和几何统计。

如果缺少足以支持三维本构的参数，先交付纵向刚度/一维响应的实验对照，三维场维持带先验假设的探索状态。无法支持独立对照时，报告具体缺口，不能人为调到吻合后称为预测成功。

## 4. 工程基准：WWFE E-glass/MY750 环氧

### 4.1 锁定具体材料

采用 Soden、Hinton、Kaddour 的 WWFE 输入数据中的 Silenka E-glass 1200 tex / MY750/HY917/DY063。不要与同表另一个 E-glass/LY556 体系混用。

原论文：*Lamina properties, lay-up configurations and loading conditions for a range of fibre-reinforced composite laminates*，1998，DOI [10.1016/S0266-3538(98)00078-5](https://doi.org/10.1016/S0266-3538(98)00078-5)。作者章节可在[出版方预览](https://api.pageplace.de/preview/DT0400.9780080531571_A23527204/preview-9780080531571_A23527204.pdf)读取；该 PDF 索引第 48、49 页包含组分与层片表格。

| 参数 | 基准值 | 用法 |
| --- | --- | --- |
| 纤维体积分数 | 0.60 | 基准微结构比例 |
| 玻璃纤维杨氏模量 | 74 GPa | 理想化组分输入 |
| 玻璃纤维泊松比 | 0.20 | 理想化组分输入 |
| 环氧基体杨氏模量 | 3.35 GPa | 理想化组分输入 |
| 环氧基体泊松比 | 0.35 | 理想化组分输入 |
| 层片纵向模量 E1 | 45.6 GPa | 外部基准比较 |
| 层片横向模量 E2 | 16.2 GPa | 外部基准比较 |
| 层片面内剪切模量 G12 | 5.83 GPa | 外部基准比较 |

这些是公开 benchmark 的输入/典型汇编值，不能全部视为同批次独立直接测量。实际数据卡进一步区分取值依据、初始模量及假设；不将其他推导值标成额外测量。

纵向混合律给出 `0.60×74 + 0.40×3.35 = 45.74 GPa`，与基准纵向模量接近。这是很好的单位和轴向检查，也说明只训练一个网络预测 E1 的研究价值有限。

更有意义的任务是横向/剪切响应、纤维分布与局部应变集中。在这些方向，理想两相模型和公开层片参数未必一致；需要分开报告代理误差与物理模型偏差，不能让 AI “修正数字”掩盖缺少的机制。

### 4.2 从二维到三维

先做周期性二维纤维截面的平面应变基准，验证横向面内刚度和场。平面应变的受约束刚度不是自由三维试样的 E2；不得直接拿二者比较。

需要完整有效工程常数时，再采用三维挤出周期 RVE，施加六个独立小应变，求 `C_eff`；由其逆矩阵计算工程常数，并检查尺寸和离散收敛。纤维半径、排布和界面假设单独登记。

该小型基准不需要真实 CT 即可跑通软件。玻璃/环氧 CT 另用于几何导入验证，除非证据确认牌号/批次和测试匹配，不参与该 WWFE 材料的独立精度验收。

## 5. 首条闭环的具体定义

### 5.1 任务边界

| 项目 | 建议定义 |
| --- | --- |
| 真实研究材料 | DTU UD CF/VE；牌号、试样与型材关联在数据审计中登记 |
| 工况 | 原测试对应的室温准静态条件；先取已审计的初始近线性段 |
| 宏观几何 | 按原始压缩试样尺寸和标距定义的固定长方体族；夹持/加载影响另记 |
| 最早指标 | 纵向小应变刚度、宏观轴向响应和参数敏感性 |
| 微结构指标 | 纤维体积分数、取向分布、孔隙及代表性尺度 |
| 场输出 | 参考数值场与代理场，明确其假设；有完整本构证据后才扩大验收范围 |
| 首期设计变量 | 受限纤维比例、取向统计；孔隙仅在几何和参考方法验证后开放 |
| 暂不预测 | 失效强度、纤维屈曲/扭折、分层、疲劳、任意材料及任意 CAD |

宏观试样的几何/夹具必须与原测试说明核对。自由均匀应变 RVE 与被夹持试样的表观刚度不是同一个观测量。

### 5.2 工作顺序

1. **数据审计与参数识别**：读小型力学文件，确认单位、标距和测量方法；建立来源分类；保留复合材料对照；不运行下载脚本。
2. **小型玻璃/环氧基准**：解析混合律、周期 RVE 和参考场；核对坐标/单位、能量和有效刚度。
3. **CF/VE 参考模型**：使用独立组分参数及其先验区间；先宏观纵向响应，再少量 CT 子体积的取向/RVE 研究。
4. **数值训练数据**：先 50–100 个真实求解算例检查流程和单例成本，再根据误差学习曲线扩到约 500–2,000 个微结构算例。这些是计算样本，不是假造实验。
5. **机器学习比较**：工程常数采用混合律/Mori–Tanaka 等适用基线、GP 或树模型；完整场才比较 POD/降阶、U-Net 与 FNO。是否保留复杂模型由保留集精度和端到端成本决定。
6. **分组实验对照**：按 A/B/C 型材轮换保留，校准只用训练型材。选择模型后保留最终未参与决策的验证资源；只有三个型材时诚实报告证据规模。
7. **受约束候选设计**：输出目标刚度、密度或成本权衡下的候选集合，再用参考计算复核。工艺可行性和新材料实验另行确认。

### 5.3 为什么最初不一定需要 FNO

小应变线弹性下，固定结构的响应对载荷是线性的。RVE 可以保存独立加载基底并按线性组合重建；仅改变载荷幅值不需要重新训练模型。

均匀长方体的轴向响应也有解析基线。机器学习价值主要来自大量不同微结构、空间变化取向/孔隙及复杂场的重复查询。先测量传统求解和降阶基线，再判断 FNO 的收益。

不要把同一算例缩放出的多个载荷幅值分到训练和测试两侧；不同 CT 裁剪/分辨率来自同一原体积时，也必须同组。

### 5.4 验收与研究指标

- 参考求解：网格与 RVE 尺寸收敛、周期约束、刚体模态、张量对称/正定、边界和平衡。
- 代理：`C_eff` 误差、各工程常数误差、能量/响应量误差、位移/应变/应力场误差、关键区域和 OOD。
- 实验：初始刚度与宏观响应，含测量和参数区间；不能用数值局部场验收替代实验局部场验收。
- 基线收益：比简单模型增加了多少精度，减少多少真实求解时间；是否支持更好的选样/候选。
- 逆向：候选由独立参考复核，真实实验目标达成另记；预测刚度通过不表示强度安全。

阈值在样本审计和参考收敛后冻结。可对代理相对参考解设严格工程指标，但实验差异应结合噪声和模型偏差，不能统一承诺 1% 精度。若取向差异对刚度的影响低于观测噪声，报告“不可区分”，不强行给三个型材排名。

## 7. 空间和下载策略

本轮只查阅论文、网页与仓库元数据，没有下载大型 CT、训练权重或安装计算框架。

DTU 主数据仓库约 9.7 GB，其中一张 SEM TIFF 约 9.6 GB。它不代表力学表格本身需要这么大；首期可以选择曲线、Excel 和待审查脚本，再按需取图像。[仓库文件清单](https://zenodo.org/records/18435237)。

A/B/C 的三个 CT HDF5 文件分别为 41,743,554,560 字节，约 41.7 GB（38.9 GiB），三者合计约 125.2 GB。元数据均标注 CC BY 4.0。单个 CT 文件也不适合整块加载到普通电脑内存；实施时检查 HDF5 分块布局、可否远端读取、裁剪成本和实际存储上限。[A](https://zenodo.org/records/18364215)、[B](https://zenodo.org/records/18370051)、[C](https://zenodo.org/records/18364338)。

数据准入建议：

1. 先缓存 DOI、许可证、版本、文件字节数和校验值。
2. 小型曲线和参数优先，重复的已处理/未处理纤维 Excel 按验证目的选择。
3. 不默认下载 9.6 GB SEM 和全部 CT；按 ROI/文件组织评估获取成本。
4. 实测缩略和裁剪方法，原始资产按需保留。服务器不支持远端读取时，不宣称能零成本截取小块。
5. 程序默认只提供少量经许可审查的示例和数据卡，大型研究数据由项目空间管理。

## 8. 如何推进到分子结构反设计

在首个数据案例通过后，建立明确化学组成的树脂研究系列；例如 DGEBA + 指定胺固化剂。这个系列是新材料数据任务，不能把 MY750 或乙烯基酯的参数改名后移植过来。

```text
树脂/固化剂组成与比例
  → 固化程度、网络统计、温度/速率相关基体参数
  → 指定纤维/界面/孔隙与取向的 RVE
  → 层片或试样刚度/响应
  → 配方与工艺候选
  → 实验反馈
```

先做小数据 GP/贝叶斯优化与基体控制试验，再考虑分子生成。分子模拟需要独立环境、专用力场、交联方法和时间尺度校准，不用现有无机核心 MLIP 越域执行。

玻璃纤维作为近似固定增强相，适合后续透明树脂系列的受控研究；CF/VE 则保留为真实多尺度数据和迁移验证案例。CF/PEEK 等热塑性方向在温度、结晶和工艺证据齐备后扩展。

## 9. 首期可交付成果与剩余决策

首期成果应是一张有范围的材料卡、一套可复现数据审计与参考计算、一个有基线对比的代理、分组实验对照、3D/场产物及候选复核报告。

必须分开标注“数值通过”“该观测量实验对照通过”“分子层未接入”“强度未验证”。论文原工作中的成功不计作本项目已经验收。

启动 M7.0 时需要冻结：主案例是否采用上述 DTU UD CF/VE、是否具备补充试验条件、缺失碳纤维参数如何处理、允许的磁盘/GPU/HPC 资源、以及目标先限定纵向刚度还是扩到完整弹性张量。

建议在这些条件核验后继续 M7.1/M7.2。无需提前安装大批框架；先证明数据关联、参考模型和独立对照能成立。
