# 原子计算自动流程的单位与交付修复

2026-10-06。复现输入：自动选势、优先已安装模型、最多 3 步固定晶胞弛豫，输出能量、原子受力、收敛状态、报告和 3D 结构。

## 原因

1. 计划校验把 `{value: null, unit: "eV"}` 的未知计算输出当成未经用户确认的目标单位，计算前即停止。不能以此认定机器学习势、模型权重或结构文件过大。
2. 复制通用示例不会选择原子结构，也不会建立当前对话的计算范围。不能擅自把项目里的其他结构当成本轮研究对象。
3. 本地 GPT-OSS 20B 实测会混淆结构 ID、评估 ID，或在提交真实计算后返回空消息、协议标记。多步骤的形式正确不代表实际产物交付成功。

## 同一套执行引擎内的修正

- 单位来自注册计算工具的原生输出合同；仅匹配本轮要求的未知能量/受力，不能借此编造数值阈值、换单位或增加权限。原有来源单位校验保留。
- 对包含明确结构 ID、固定晶胞、明确最多 1–64 步且无比较任务的自动弛豫请求，绑定一个 `materials_science` 后端步骤。完整原请求保存在约束中。复杂任务仍使用原研究计划解释器。
- AI 仍从真实候选中选势。`auto_plan` 返回实际评估 ID、候选证据及可直接调用的 `nextCalls`；`auto_run` 返回实际工作流 ID 和查询调用。未满足适用性、权限和下载范围的调用继续拒绝。
- 评估、提交不是完成。任务监督必须检查实际计算终态，并核对本任务、本步骤、本版本的结果 JSON、报告和最终结构文件及 SHA-256。
- 复用已有工作流查询回执，把其真实子计算 ID 纳入原任务记录。若本地模型后续响应格式失败，但同一任务的计算已经完成，可只查询、核验并交付现有结果；不重算、不再调用模型，不把模型协议资格或科学质量标为通过。预算、取消、权限、失败计算与被篡改文件不能走这条交付路径。
- 最终回答由已核验报告与真实受力数组组成，保留计算 ID；现有聊天产物卡据此展示 3D、前后对比和文件入口。科学质量继续为 `needs_review`。
- 未绑定结构/计算范围时，聊天显示正常的输入补充指引，运行记录标记 `blocked`；不调用模型、不下载、不计算、不显示内部调用失败。

## 用户入口

打开 **模型目录 → 机器学习势 → 模型下载与自动分析**。选择已导入结构、设置任务与步数，点击 **授权对话助手分析**，发送系统填入的请求。

试用内置结构可点击硅晶体示例的 **在对话中试用**。它明确选择内置 8 原子硅结构和最多 3 步的固定晶胞 FIRE 范围，再填入提问；不会把未提供的结构假装成真实研究输入。

真实模型探针使用本机 LM Studio、`openai/gpt-oss-20b`、Codex App Server，隔离项目和数据库、明确授权的内置硅测试结构，下载额度为 0。不改用户对话、模型设置或原有结构。真实报告与日志在 `runtime/agent/atomic-agent/`，不会作为科学精度验收或商业付费模型资格。

本修复减少一个已知计算流程对模型格式稳定性的依赖，不能保证该本地模型对任意复杂研究任务不再返回无效参数。模型未实际提交计算、计算未成功、产物丢失或证据不完整时，仍不能报告成功。

## 本轮验收结果

- 类型检查与 600 行文件限制通过；431 项回归测试中 430 通过，1 项既有身份服务环境测试跳过。
- 实际桌面 IPC/界面：原始无结构提问返回正常补充指引，运行记录为 `blocked`，无错误事件、无模型推理。
- 真实 GPT-OSS 20B + Codex App Server：明确的 8 原子硅测试结构，禁止下载；AI 选择已安装 `mace-mp-0b3-medium-d3-bj-pbe-si`，真实能量 -45.47263954171467 eV，停止原因 `converged`，最多 3 步，实际执行 0 步。已保存并核验 17 个产物，包含中文/英文报告、完整受力及最终结构。用时 116.6 秒。
- 本地模型未稳定完成后续有效回答，本轮走已完成计算回执的核验交付路径。任务状态为 `completed_with_limitations`；没有重算，没有新增下载，不声称模型工具链对任意任务均稳定。
