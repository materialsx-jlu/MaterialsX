# 机器学习势目录响应优化

## 改动

- 目录元数据按签名版本缓存，目录更新时失效。下载与浏览不再逐个模型重新解析完整目录。
- 目录按 24 条分页显示，筛选只遍历一次；模型状态用 ID 索引匹配。
- 目录快照使用浅响应式数据，避免为证据、能力和示例逐层创建代理。
- 首帧先呈现目录，下一帧开始读取安装状态。界面显示“检查安装状态”，不把尚未读取的状态视为未安装。
- 模型发现、下载与自动分析、结构计算按展开加载；结构计算代码也按需加载。
- 只在下载或加载过程中持续刷新。查看静止的模型详情不再定时扫描全部权重。
- 并发安装状态请求共用当前扫描；请求完成或失败后不缓存状态。扫描期间收到变更通知会追加刷新。

权重指纹检查、撤回校验、实际模型加载和计算前的验收保持执行，元数据缓存不赋予计算权限。

## 本机验证

在隔离用户目录的真实 Electron / IPC 环境测试，176 个目录条目、每页 24 张卡片：

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 打开时后台读取次数 | 9 | 1 |
| 首次卡片绘制 | 30.1 ms | 15.6 ms |
| 初次安装状态扫描 | 1946.7 ms | 565.1 ms |

耗时是本机单次观测，受硬盘缓存、模型文件和系统负载影响，不是所有设备的性能承诺。首帧测试观察到的渲染长任务均为 0。

验证了折叠区域不发起读取、静止详情不轮询、中文/英文示例、展开后的模型发现与空间统计、结构导入。另完成 22 个权重详情的 44 次中英文布局检查、458194 字节的官方权重真实下载与清理、CHGNet 实际加载验证，以及硅晶体对话示例准备。

运行回归：

```bash
npm run build:desktop
node_modules/.bin/electron apps/desktop/potential-catalog-performance.cjs --assert
node_modules/.bin/electron apps/desktop/potential-models-ui-smoke.cjs
npm run check
npm test
```

第一项不下载模型、不调用付费服务；第二项下载小型公开权重并验证已存在的 CHGNet。结果写到被 Git 忽略的 `runtime/ui-layout/`。
