## 使用

在项目根目录执行 `npm run desktop:start`。已有 M6.1 本地运行时即可使用；缺少运行时的开发环境先按 [M6.1 运行时文档](runtime.md) 安装。静态浏览不会加载势权重，原生格式解析仍使用现有隔离 Python 环境。无需登录云端，也不消耗积分。

1. 在左侧选择本地项目，进入「模型目录 → 机器学习势 · Checkpoints」。
2. 点击「导入结构文件」，选择 CIF、XYZ、extxyz 或 POSCAR，然后点击「查看结构 3D」。分子和 slab 可以预览；核心单点计算仍保留 M6.1 的三维周期边界检查。
3. 拖动旋转，右键拖动或 Shift 拖动平移，滚轮缩放；「重置 / 适应视图」恢复初始视角。样式可选球棍、球和棒。
4. 点选最多三个原子，也可通过坐标表选择。两点显示距离，三点显示以第二点为顶点的角度；再次选择同一原子取消，第四次选择开始新的测量。
5. 「导出 PNG」通过原生保存对话框保存当前画面；「导出原始结构」导出经哈希复核的源文件，保留原始字节与格式。完整的计算 JSON、报告和事件日志可从产物卡片或详情打开。

单点完成后，真实结果卡片提供「查看 3D 与产物」。计算详情包括模型哈希、CPU/精度、资源预算、选择来源、能量与应力。仅有真实 N×3 力数据时启用力模长着色，单位 eV/Å，副本沿用源原子的力。颜色按当前最大力自动缩放，需按绝对数值判断量级，不能把不同任务的相同颜色当作相同力。

聊天中的助手完整消息若引用本项目已登记的任务 ID 或产物 ID，会显示同一结果卡片。未知 ID 不会授权文件读取；Markdown 文字、HTML 或远程地址不能定义 3D 场景。流式消息不会反复创建场景。

## 显示与科学边界

- 晶胞使用三个完整晶格向量绘制 12 条边，支持三斜晶胞；超胞每轴 1–3 倍，只允许沿 PBC 为真的轴复制。显示上限 4096 个原子，源结构不变，超胞不进入计算。
- 测量是所选**显示副本的笛卡尔距离**，单位 Å；不施加最小镜像变换。角度单位为度，重合坐标明确显示未定义。
- 邻接连线依据内置常见元素的近似共价半径推断，既非化学键级也非计算产物；仅连接当前显示副本，不添加未显示的周期镜像。没有半径的元素仍可显示，并注明未推断连线。
- 空间网格邻接搜索最多 200,000 次候选检查、12,000 条连线、每原子 24 条邻接；超过上限关闭全部连线并提示。完整坐标仍可读和导出。
- 占位率、解析警告与阻断问题保留；可视化不授予计算资格，更不将 `needs_review` 升级为科学通过。
- 查看器坐标/晶胞显示范围限制为绝对值不超过 10⁶ Å。无法渲染时保留完整源坐标表与导出，不丢弃源数据。

## 工程与安全

固定依赖 `3dmol@2.5.5`，BSD-3-Clause，[许可原文](../third-party/3DMOL_LICENSE.txt) 随资源分发。采用官方 [GLViewer](https://3dmol.org/doc/GLViewer.html) 与 [GLModel](https://3dmol.org/doc/GLModel.html) 的数据/交互 API。不调用该库的下载、远程请求、用户脚本或用户文件解析入口。

查看器是一个固定本地 HTML/脚本入口，Vite 分离打包。仅打开面板时加载，全应用最多一个活动场景；关闭时清空场景、主动释放 WebGL context，再移除 iframe，使 frame 内的库监听器/观察器一同释放。iframe 用于可信组件的生命周期隔离，`allow-scripts` 与 `allow-same-origin` 组合不是不可信 HTML 的安全沙箱；不向其中传入任何用户 HTML。

frame CSP 使用 `default-src 'none'`、`script-src 'self'`、`connect-src 'none'`，不允许动态求值。上游打包代码包含字符串回调的 eval 分支，因此 Vite 会提示；本项目仅使用自己定义的函数回调，合同拒绝脚本字段，CSP 阻断字符串求值。查看器不需要 CDN、外部图片、字体或科学数据上传。

主进程新增三个窄 IPC：`atomistic:view`、`atomistic:export-structure`、`atomistic:export-png`。输入只有项目/结构/任务/产物 ID，不能传路径或 URL。逐次检查项目归属、已完成任务、结构产物类型、realpath、每级 symlink、大小及所返回字节的 SHA-256；支持 macOS `/var` 与 `/private/var` 的同一根目录别名。文件改动、删除、跨项目或不匹配的力数组均拒绝。

frame 消息严格校验 source、origin 与 Zod 合同；`file:` 加载兼容浏览器发出的 `null` origin，仍须匹配当前 frame。坐标、显示配置和消息有数组上限。PNG 校验签名、IHDR、解码结果、最大 4096×4096 且不超过 800 万像素/8 MiB，主进程解码再编码后写入。保存位置只来自用户的原生对话框。

WebGL 创建失败、context lost 或本地模块初始化超时均显示降级状态；坐标表和源文件导出保留，PNG 不会把空白视图当成功。配色直接订阅全局「Materials 深色 / Codex 浅色」，未新增另一套偏好开关。

新合同 `m6.2-v1` 的六份 JSON Schema 位于 `schemas/m62/`，未修改 M6.0 冻结合同、策略或样本。M6.1 历史 source snapshot 保留为历史证据；本次变更另记 M6.2 source snapshot，不重写既有证据。

## 复验

```bash
npm run check
npm test
npm run m6:contracts:check
npm run m6:audit
npm run m61:contracts:check
npm run m62:contracts:check
npm run m6:ui:viewer
```

`m6:ui:viewer` 使用独立临时 userData 与团队几何样本，通过真实原生选择器 IPC/本机 Python 导入并运行一次 CHGNet CPU 单点；结果验证后清理临时项目，证据输出到 `runtime/m6/ui/`。会创建临时文件和一次本机计算，不调用 LLM、支付或积分接口。`m62:verify` 合并上述检查，依赖已安装的 M6.1 运行时。

本次未制作新版 DMG/NSIS，也未宣称 Windows 或科学参考验收通过；相应测试已接入双平台 CPU CI，成功运行证据需由真实运行补充。
