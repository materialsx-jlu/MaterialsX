# 模型下载、加载与对话分析

更新日期：2026-10-03。

## 在哪里操作

打开「材料模型目录 → 机器学习势 · 全部目录」。目录把模型系列、具体权重、训练方法和工具分别展示。只有具体权重对应可下载文件；同一家族中不同版本的权重不能互相替换。

状态筛选提供「已适配计算」「本机可计算」「可下载」「已下载」。点开具体权重后，介绍、下载与运行、使用例子排在前部；能力、环境、来源和许可信息可以展开查看。Skills、研究模型、势目录与发现候选共用使用例子组件，支持中英文和填入对话输入框，跟随全局主题。

- **下载权重 / 继续下载**：从目录记录的官方地址保存文件并显示进度。已知发布者 SHA-256 的文件在完成下载后核对摘要和体积；暂停可续传。上游未给出可信摘要的文件记录本地摘要，暂停后重新下载，不标记为已通过目录指纹校验。
- **导入权重**：通过系统文件选择器导入，必须有目录记录的预期摘要、大小且一致。没有预期摘要时仅提供官方来源下载。
- **加载验证**：仅对已适配且本机权重与环境已就绪的模型提供。实际运行受限子进程，读取真实权重、验证依赖身份并返回元素与内存信息。此操作结束后释放内存；计算任务仍会加载模型，不是常驻推理服务。
- **分析结构**：进入现有结构选择与任务界面。导入 CIF、POSCAR、XYZ/extxyz 后，设置任务和下载额度，系统筛选候选，再查看计算计划。
- **打开文件位置**：重新验证实际文件摘要后显示缓存或安装文件的位置。
- **清理下载文件**：先按当前占用清单核对，再经原生确认删除本机下载副本。通用目录下载也进入「空间与离线文件」统计与清理。计算环境、原始结构、结果、复现回执保留。

下载只处理目录指定的 HTTPS 来源，逐次检查重定向，拒绝本地/未批准目标；最大文件 3 GiB，检查磁盘空间，流式写入临时文件，完成检查后提交。权重缓存按来源、版本、摘要和体积隔离；历史或已撤回版本的下载副本仍能从空间管理清理。

## 下载和可计算的区别

当前目录有 **176 条资源、22 个具体权重、9 个计算接口**。下载一个权重文件不会自动安装框架、补齐配置文件或建立计算接口。通用下载保存在用户数据目录 `catalog-weights/`，不会进入已审核运行包注册表，也不会执行或反序列化下载文件。访问受限的来源仍需要官方授权；暂无 Hugging Face 账户令牌管理。

已有计算接口包括：

| 系列 | 接入版本 |
| --- | --- |
| MACE | MACE-MP-0b3 medium、MACE-MP-0b2 small、MACE-MPA-0 medium |
| CHGNet | 0.3.0、r2SCAN |
| SevenNet | SevenNet-0 11Jul2024 |
| ANI | ANI-2x ensemble（受限中性孤立分子） |
| NEP | 硅 NEP4 三体参数（纯硅） |
| 组合势 | MACE-MP-0b3 + PBE-D3(BJ)（受限纯硅探索） |

本机能否加载还取决于对应计算环境和平台状态。开发版的环境准备命令显示在具体权重详情；安装版由发行资源提供。下载功能覆盖已记录官方文件来源的具体权重，未逐个验证其框架加载；加载按钮仅对上述接口的就绪安装开放。Windows/GPU、其他势家族接入与领域精度验收按原计划推进。

## 对话示例

先打开研究项目，展开「模型下载与自动分析」，点击 **「试用：硅晶体自动分析 → 在对话中试用」**。

按钮会导入团队内置的 8 原子硅结构，为当前对话设置最多 200 MiB 权重下载和最多 3 步固定晶胞弛豫的范围，并填入输入框。没有对话时会创建一个；按钮不会自动发送请求。发送前仍需配置可正常调用工具的本地或平台对话模型。

填入的任务类似：

> 请分析已导入的 8 原子硅晶体。根据元素、周期性、任务和本机资源选择合适的机器学习势，优先使用已安装模型。执行最多 3 步固定晶胞弛豫，说明选势理由，输出能量、原子受力、是否收敛、中文报告和 3D 结构。

助手通过 `materials_science auto_plan → auto_run → auto_get` 完成候选筛选、必要下载、加载复核、实际计算与报告。选择依据是元素、边界条件、相互作用、任务与本机资源；不将目录条目数或模型名字当作精度排名。当前结构的正式科研结论仍需参考数据验证；达到步数上限时如实报告未收敛。

自己的材料使用「选择本地结构」导入，设定任务后点击「授权对话助手分析」，再发送需求。仅输入“预测某材料性能”不足以确定原子结构、电荷、自旋或计算物理范围，需要提供结构和必要条件。范围只对当前对话与结构生效，重启后重新授权。更换结构或正式用途不会沿用示例授权。

计算发生在本机；调用平台 LLM 时，其对话 Token 仍遵守现有积分计费。模型选势理由由 LLM 生成，适用性、下载和真实产物由运行服务复核。能力较弱的对话模型可能仍无法完成多步工具调用。
