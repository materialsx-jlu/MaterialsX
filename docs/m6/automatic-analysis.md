# M6.8 / M6.9 下载挂载与自动分析

实现日期：2026-10-02。macOS arm64 工程验收通过；科学结果保持 `needs_review`。

M6.10 在此闭环上新增 SevenNet 独立环境，当前共六个可计算接口；本文五接口表是 M6.8/M6.9 的阶段记录。新模型的运行范围、环境体积和候选补齐见 [M6.10 文档](sevennet-adapter.md)。当前任务 Skill 元数据为 `skills/atomistic-m610.json`。

## 使用入口

启动开发版：`npm run desktop:start`。进入「模型目录 → 机器学习势 · 全部目录 → 下载管理与自动分析」。已接入模型详情也有管理入口。页面继承 Skills 的卡片、详情和全局深色 / Codex 浅色主题。

### 下载与挂载

首批支持五个计算接口：

| Checkpoint | 环境 | 本轮情况 |
| --- | --- | --- |
| MACE-MP-0b3 medium | 既有锁定 MACE CPU 环境 | 回归实算通过 |
| CHGNet 0.3.0 | 既有锁定 CHGNet CPU 环境 | 回归实算通过 |
| CHGNet r2SCAN | 共享 CHGNet 环境 | 回归实算通过 |
| MACE-MP-0b2 small | 共享 MACE 环境 | 新增、官方冷下载及实算通过 |
| MACE-MPA-0 medium | 共享 MACE 环境 | 新增、官方冷下载及实算通过 |

三种扩展包可按需下载、取消、续传、导入准确身份的本地权重、停用和卸载。两个核心势仍随既有运行时管理。权重安装不会再次复制 Python / PyTorch 环境。

新增权重分别为 67,622,684 / 79,462,305 bytes，共 140.27 MiB。`small` 是架构尺寸标签，并不保证发布文件仅几 MB。下载数据写入 `<MaterialsX userData>/scientific-packages/<id>/<sha256>/`，携带许可通知及身份记录。卸载只删除此包的用户缓存，保留共享环境；安装包自带的只读权重可以停用，不能通过缓存卸载释放。

来源、资产哈希、大小、代码 revision、依赖锁、适配器、基础环境、实际读取元素及加载内存记录在 `models/potentials/packages-m68.json`。只允许审核条目和受控适配器，不接受模型生成的下载 URL、代码或哈希。其他目录条目仍须审核和适配后才能运行，未实现论文持续增补。

### 手动审阅自动计划

1. 用原生文件选择器导入 CIF / POSCAR / XYZ / extxyz；选择真实结构 ID。
2. 填写中文或英文需求，明确材料域、单点或固定晶胞弛豫、步数、力阈值及最多下载量。
3. 点击「检查候选并生成计划」，审阅候选与排除原因。页面的“小/快速”偏好只提供资源选择建议，不是准确性排名。
4. 冻结所选计划，再点击「批准计划并执行」。程序必要时下载，执行阶段 B 检查，再运行真实科学 worker。
5. 查看真实终止条件、双语报告、文件哈希、3D 结构和优化前后对比。达到最多步数并不意味着收敛。

### AI 自动选择与运行

选好结构、任务与预算，点击「授权本对话 AI 选势、下载和分析」。这会绑定当前项目、对话、结构和明确参数，并将示例填入输入框；之后由用户发送请求。可使用 LM Studio 本地模式，或现有 MaterialsX 平台模式（仍需既有账户、额度与云端数据确认）。

AI 使用 `materials_science`：

- `auto_plan`：根据阶段 A 返回的审核候选、证据和限制进行选择；未安装但符合下载范围的包可入选。
- `auto_run`：引用本轮候选 ID 和证据，冻结计划，在此前明确授权范围内必要下载并实算。
- `auto_get`：等待真实进展/终态，返回有界结果与已登记产物 ID；`auto_cancel` 取消自己创建的流程。

聊天输入区显示当前科学范围，可一键清除科学及下载授权。没有自动分析授权，以上操作会被拒绝。普通 M6.4/M6.5 科学授权不包含下载许可。平台只获得批准的提示、结构摘要、候选与有界结果；完整坐标、力数组、权重、轨迹和本机输出路径留在本机。计算本身不扣平台积分，模型请求继续受 M5 原有计量限制。界面支持两种语言；LLM 是否正确选择模型仍依赖其工具调用能力。

## 工作流与恢复

计划冻结请求、结构摘要、注册表身份、模型 SHA、依赖锁 SHA、下载量、证据、选势依据和计算预算，并对整份计划计算哈希。工作流记录存放于 `<userData>/potential-workflows/`。

阶段 A 使用审核过的 checkpoint 检查记录和可用本机能力回执；阶段 B 必须检查本机真实文件、实际加载元素、依赖锁、项目内结构及任务适用性。目录文字和模型声明不能代替验证。

状态为等待审批、下载、复核、排队、运行、完成、失败、取消或中断。重启将正在执行的流程标为中断，不自动续跑。用户点击「按原计划恢复」时重新检查冻结身份：已完成且产物完好的任务直接恢复结果；未完成任务在显式恢复后开始新的计算，避免默默重复执行。目录、结构或环境变化需要重新制定计划。下载任务与科学任务都可取消；正在使用的权重不能停用或卸载。

## 我的 Skills

「Skills → 我的 Skills」支持名称、中英简介/步骤、一到两个中英例子、校验预览、保存版本、编辑、停用和删除。默认新增加 `materials-skill-creator`；本地 AI 可调用 `skill_draft` 将经校验的草稿显示到此编辑器，用户审阅后保存。平台模式可读取用户已批准点名的 Skill，但本轮没有开放云端 `skill_draft` 写入工具；可在编辑器创建或修改。

用户文件存放在 `<userData>/skills/<name>/SKILL.md`，`materialsx.json` 记录版本、启用状态、内容哈希和受控目录/工具依赖，`versions/` 保存历史版本快照。暂不提供版本回滚按钮。只有内容哈希、名称、目录依赖校验通过的用户 Skill 才进入 Skills 列表、`skill_search`、`@` 和 Pi 资源加载；停用项不传给 Pi。新 Skill 不能覆盖内置 Skill、携带脚本或任意安装依赖，也不授予下载/执行权限。

修改 Skill 需要对话空闲，防止运行中的指令发生变化。更新使用期望版本号，拒绝覆盖冲突。当前默认为 92 个内置 Skill，用户 Skill 另计。两项材料抽取 Skill 原始文件没有改动。

## 验收与限制

命令：

```bash
npm run m68:contracts:check
npm run m6:mounts:test
npm run m6:pi:automation:test
npm run m6:ui:automation
npm run m69:verify
```

已完成五种 checkpoint 的真实 CPU 单点回归，两条中文/英文请求的真实固定晶胞弛豫，其中一条从未安装包开始自动下载；旧核心模型的真实 FIRE 变胞、NVE/NVT 及取消/恢复回归通过；原生 Electron 页面、用户 Skill 生命周期及 `@` 搜索、显式对话授权但不自动发送、3D、双语及两主题/窄窗检查通过。当前任务 Skills 元数据使用 `skills/atomistic-m68.json`，历史 M6.4 元数据保持不变。另以真实 Pi SDK、Go 网关验证器和离线脚本化 Responses 测试串通自动调度到真实计算。**离线脚本化模型回复不等于商业或本地 LLM 自主推理质量验收**；本轮未调用真实付费模型、支付或生产网关。

下载单元测试覆盖取消后重启续传、断网、Range 错误、SHA 错误、未经许可的重定向、磁盘不足、符号链接、活跃包删除拒绝；工作流测试覆盖预算、域外/正式模式拒绝、项目范围、证据伪造、计划变更和重启不自动执行。

本轮仅 CPU、无机三维周期晶体探索、单点和固定晶胞 FIRE 自动化。新 MACE 的 MD/变胞入口尚未纳入本阶段自动流程；旧模型的 MD/变胞能力保留。五模型的本机运行成功不证明独立 DFT 精度，也不证明孤立分子、高分子、表面、电荷或自旋适用性。Windows 实机、签名发布、保留集精度与 M6.10/M6.11 新适配器/持续发现均待后续验收。
