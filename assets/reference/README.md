# Electron runtime icon reference

`electron-runtime-icon-1024.png` and `electron-runtime-icon.icns` were extracted from the locally installed Electron 44.5.0 runtime (`Electron.app/Contents/Resources/electron.icns`). They show Electron's three-orbit icon and are kept only as a visual reference. The MaterialsX application icon is in `assets/brand/`. The Electron package license is copied in `ELECTRON_LICENSE.txt`; this reference is not a MaterialsX-original logo.
